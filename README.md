# EduGenie

EduGenie is an AI-powered educational assistant built with:

- Python
- FastAPI
- Google Gemini
- HTML
- CSS
- JavaScript

## Features

### 1. Ask a Question

Students can ask academic questions and receive AI-generated explanations.

### 2. Explain a Concept

Explain difficult concepts according to:

- Beginner
- Intermediate
- Advanced

### 3. Generate Quiz

Paste study material and generate:

- 3 MCQs
- 4 options per question
- Correct answer
- Explanation

### 4. Summarize

Convert long study material into concise revision notes.

### 5. Learning Path

Generate a multi-week learning plan for a topic.
